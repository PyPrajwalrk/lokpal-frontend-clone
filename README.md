# Lokpal of India — Frontend

A React-based frontend project recreating the Lokpal of India website interface.

**Developed by:** Laala  
**Project Type:** Frontend Web Application  
**Status:** Frontend Development

## Overview

This project aims to provide a clean, responsive, and user-friendly interface inspired by the Lokpal of India website. It includes navigation, complaint-related pages, information sections, and member profiles.

## Features

- Responsive homepage layout
- Header with official-style branding
- Navigation bar with dropdown menus
- Hero image slider
- Complaint section with four navigation cards
- How to File Complaint section
- Latest Information section
- Calendar component
- About Lokpal section
- Members of Lokpal cards with detail popups
- e-Filing interface
- Complaint-related pages
- React Router navigation
- Organizational Structure PDF link

## Technology Stack

- React.js
- JavaScript
- CSS
- Vite
- React Router DOM

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd lokpal-frontend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

## Available Scripts

- `npm run dev` — Start the development server.
- `npm run build` — Build the production frontend.
- `npm run preview` — Preview the production build.
- `npm run lint` — Run ESLint checks.
